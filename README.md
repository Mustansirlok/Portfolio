# 🌐 Mustansir Lokhandwala — Personal Portfolio & Technical Showcase

A lightweight, highly optimized, and modern developer/technician portfolio designed to showcase hands-on projects, virtualized lab setups, technical skills, and career progression. Built with a bespoke **terminal/network-inspired dark aesthetic**, complete with subtle SVG architecture diagrams and a traceroute-styled trajectory roadmap.

---

## ⚡ Features & UI Highlights

* **Network-Inspired Aesthetic:** Dark theme featuring custom CSS grid textures, signal accent colors (`#4FD1C5`), dynamic pulse animations, and trace-route visual elements.
* **Interactive Home Lab Diagram:** Integrated inline SVG layout visualizing an enterprise Active Directory forest structure (Domain Controller, GPOs, OUs, and Workstation client VMs).
* **Skills "Interfaces" Table:** Organized multi-column matrix categorizing technical competencies across Routing & Switching, Packet Diagnostics, Systems Administration, and Scripting.
* **Featured Projects Grid:** Card-based modular showcase emphasizing hands-on Cisco Packet Tracer labs, Bash sysadmin utilities, and full-stack deployments.
* **Career Routing Table:** Experience timeline formatted as a network routing table (`period | role | duration`).
* **Fully Responsive & Accessible:**
  * Zero heavy JavaScript frameworks — lightning-fast load times.
  * Mobile-first flex and CSS grid layout models.
  * Native `prefers-reduced-motion` support for accessibility compliance.

---

## 🛠️ Built With

* **HTML5:** Semantic architecture (`<nav>`, `<header>`, `<section>`, `<footer>`, inline `<svg>`).
* **CSS3:** Custom CSS variables, CSS Grid, Flexbox, backdrop blur filters, custom keyframe animations, and clamp-based typography (`clamp()`).
* **Typography:** Google Fonts ([Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)).
